# AI Link Fixer (Удаление пробелов из ссылок)

Маленькое расширение для Google Chrome, которое собирает «разбитые» пробелами ссылки (например, от ИИ-ассистентов) в рабочие URL-адреса и копирует их в буфер обмена.

## Как установить в Chrome:
1. Скачайте эту папку с кодом (или клонируйте репозиторий).
2. Откройте Chrome и перейдите по адресу `chrome://extensions/`.
3. Включите **«Режим разработчика»** (тумблер в правом верхнем углу).
4. Нажмите кнопку **«Загрузить распакованное расширение»** в левом верхнем углу.
5. Выберите папку с этим проектом.

## Как пользоваться:
1. Выделите мышкой текст ссылки, разбитый пробелами (например: `h t t p s : / / g i t h u b . c o m`).
2. Нажмите правую кнопку мыши.
3. Выберите пункт **«Очистить от пробелов и скопировать»**.
4. Вставьте готовую ссылку (`Ctrl + V`) куда угодно!
